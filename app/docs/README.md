# Host-SMR 识别

## 服务与识别

分别控制自动识别、自动映射与挂载；“飞牛硬盘归属”是单独开关，开启后飞牛会把已初始化的原生 SMR 空间归属到存储空间（仅 x86 适配，重启飞牛管理服务/系统后生效）。当前版本中 HC620 4Kn 盘还不能通过 ASM SATA 芯片识别，仅有理论可行性，不承诺支持。自动识别主要用于解决硬盘经 ASM SATA 控制器后无法被系统自动识别的问题。关闭开机服务不立即卸载正在使用的空间；停止应用只停止界面后端，已注册的开机服务不受影响。

动态扫描 PCI/libata 控制器及其全部端口，不限定厂商或 PCIe 地址。系统已经枚举的设备优先使用，普通盘直接跳过。只对有明确 ZAC 证据的失败端口作有限兼容处理，无证据不强制分类、不反复复位。

模块使用运行内核对应头文件与本机编译器构建，并校验 vermagic。AHCI 私有字段布局从当前内核 BTF 获取，不复制其他内核的结构偏移；缺少构建或观测条件时明确报错。

## 控制器选项

每块 SATA 控制器可分别设置“强制关闭 NCQ”和“强制 32 位 DMA”。设置保存在配置中，并生成 smr_policy 模块与 initramfs 钩子；**重启后生效**，关闭后重启恢复系统默认。驱动内建时拒绝设置；不会在线缩减既有 DMA 分配。控制器身份在运行系统发现，不写死 PCI 地址。

## 依赖

安装/升级时先由脚本自动安装可通过 apt 获取的软件包，再由应用内同一份检查（后端命令白名单 + 只读探测）决定能否继续。

**hard（缺任一项拒绝安装/升级，appcenter 回滚）：**
- 架构与包一致（x86 包要求 `uname -m` = x86_64）
- 系统命令：lsblk、blkid、wipefs、dmesg、dmsetup、udevadm、systemctl、modprobe、insmod、rmmod、modinfo、mkfs.btrfs、mount、umount、findmnt、sha256sum、LVM（pvcreate/vgcreate/lvcreate/vgchange/lvs/pvs）
- 随包 dmzadm 可执行且 `ldd` 动态库全部可解析
- dm-zoned 内核模块可用（modinfo 或内建）
- /sys/kernel/btf/vmlinux 存在；内核 config 开启 CONFIG_KPROBES/KRETPROBES/DEBUG_INFO_BTF

**compat（缺失仍可安装，但兼容识别不可用）：**
- gcc 或 gcc-12、make
- /lib/modules/$(uname -r)/build
- 内核版本 >= 6.12

**表现：**
- hard 缺失：安装/升级失败，安装日志（TRIM_TEMP_LOGFILE）逐项列出缺什么、为什么需要、建议安装方式；不会留下半安装状态。
- 仅 compat 缺失：安装脚本会尝试安装 gcc、make 和当前内核头文件；若仍缺失，安装成功但兼容识别不可用，安装日志和“识别”页顶部会提示原因。补齐依赖后可在识别页手动重试。
- 内核升级后缺新内核头文件：daemon 启动时重新检查，界面直接显示该缺失。
- 若系统软件源没有当前内核匹配的 headers，需先从飞牛对应软件源安装该版本头文件；脚本不会替换内核或安装不匹配的 headers。

**安装钩子时序（2026-10-29 在 .19 实测）：**
- `install_init` 在应用文件解包**之前**执行（此时 TRIM_APPDEST 不存在），不能调用包内二进制。
- `install_callback` 在应用文件就位**之后**执行；此处 hard 检查失败会让 appcenter 中止安装并回滚（实测应用目录被删除、appcenter 列表无残留）。
- 依赖检查因此放在 `install_callback` / `upgrade_callback`；`upgrade_init` 在文件替换前执行，只写日志说明检查已交给 callback。
- 命令行本地升级在 appcenter-cli 下未触发 upgrade 钩子（同版本/本地包被当作已安装），升级钩子的时序以飞牛安装器实际路径为准。

## 已知风险：兼容识别的盘在运行中掉线

兼容识别依赖按运行内核临时构建的模块。若已识别的盘在运行中掉线（链路复位后未恢复），内核可能暂时不再枚举该盘，映射与挂载会随之消失；**盘上数据不受影响**。此时到“识别”页执行一次“手动识别”，应用会重新识别并恢复映射/挂载。

## 单盘管理

管理页提供“格式化为外置盘”和“格式化为飞牛存储”。需完整序列号确认，已使用盘拒绝格式化；原生空间先在飞牛删除，再解除映射。

挂载依据当前实际 dm-zoned/Btrfs 或 dm-zoned/LVM/Btrfs 层级判断，并校验 UUID，不以保存的用途标签替代格式检测。飞牛原生初始化为一次性操作。完成后请到飞牛「存储空间管理」挂载该空间；如果空间显示“权限未适配”，点击该提示完成 ACL 转换（数据保留）。后续由飞牛处理；外置盘由应用挂载。

原生初始化受飞牛组件版本门控：storage.hdl 哈希不在适配表内时，原生按钮禁用并提示。卸载撤销自身服务与启动单元，保留磁盘数据与当前映射。
